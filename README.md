# Retro Novel FM 2.0 — FM-синт + драм-машина в стиле визуальных новелл

VST3 / VST2 / CLAP инструмент (на Mac ещё AU) для любой DAW: FL Studio, Ableton, Cubase, Bitwig, REAPER.

## Что внутри
- **24 FM-инструмента** в духе PC-98 / новелл 90-х / RPG Maker.
- **8 героинь** — у каждой группы инструментов своя девушка, своя сцена и своя реплика:
  Хикари (клавишные), Сузу (колокольчики), Сидзука (струнные), Юки (пэды и хор),
  Аканэ (лиды и медь), Рин (бас), Мидори (духовые), Каэдэ (восточные струны).
  Она моргает, качается в такт барабанам и «поёт», когда ты играешь.
- **Драм-машина**: 12 ритмов (Daily Life, Battle!, Town Theme, Sad Scene, Bossa Cafe, Eurobeat,
  Waltz, Breakbeat, Four on Floor, Drum'n'Bass, March, Lo-Fi Chill), 3 кита
  (PC-98 FM, Analog 808, 8-bit Lo-Fi), сбивки каждые 4 такта.
  - **SYNC** — играет вместе с DAW (по её темпу и позиции).
  - **ALWAYS** — играет всегда, даже на стопе.
  - Свои барабанные партии: пиши MIDI на **10-й канал** (GM: 36 бочка, 38 малый, 42/46 хэты, 39 хлопок, 45/50 томы, 37 рим, 49 тарелка).

## Управление
- Кнопки слева — выбор инструмента (цветная точка = какая героиня играет).
- ◀ ▶ RANDOM — листать инструменты.
- Ручки: тяни мышью вверх/вниз, колесо — точная подстройка, Shift — медленнее, правый клик — сброс.
- Окно можно растягивать (пропорции сохраняются).

## Скачать готовый плагин
Releases → `latest` → `RetroNovelFM-Windows-x64.zip` (или macOS / Linux).
Windows: папку `RetroNovelFM.vst3` скопируй в `C:\Program Files\Common Files\VST3\`.

## Сборка
Сборка идёт автоматически в GitHub Actions при каждом изменении.
Вручную: `git clone --recursive https://github.com/DISTRHO/DPF dpf && make`.
Звук: `plugins/RetroNovelFM/RetroFMEngine.hpp`, барабаны: `RetroDrums.hpp`,
ритмы и параметры: `RetroData.hpp`, героини: `RetroCharacters.hpp`, интерфейс: `RetroNovelFMUI.cpp`.
Все персонажи и фоны оригинальные и нарисованы кодом.
